# Зведення: адреси тактування по всіх апаратах OMAP2420

Усі значення виведено з коду розпакованого XIP (`out/roms/*.rom`, база
`0x80000000`) і **незалежно звірено байтовим тестом** (пролог функції-читача
`e92d4010`, пул `0xc6008540`, SRAM-рутина `e92d40fe`/`e92d407e`, DSP setter
`e3510009`). Підагенти `agy` розібрали N82/N93/N93i/N159 паралельно, E90 і
еталон RM-320 — оркестратор.

| апарат | функція-читач | пул `0xc6008540` | SRAM relock (`iRomSramRoutine`) | DSP setter (`iDspSetter`) | венір-читач |
|---|---|---|---|---|---|
| RM-320 | 0x800b1544 | 0x800b16ec | 0x800a7f6c | 0x800ac59c | 0x800b1c60 |
| RM-159 | 0x800b1544 | 0x800b16ec | 0x800a7f6c | 0x800ac59c | 0x800b1c60 |
| N82    | 0x800b1554 | 0x800b16fc | 0x800a7f7c | 0x800ac5ac | 0x800b1c70 |
| N93    | 0x800451e4 | 0x80045314 | 0x8003e6d0 | 0x80040c80 | 0x8004577c |
| N93i   | 0x80046248 | 0x80046408 | 0x8003eb3c | 0x80041630 | 0x800468e8 |
| E90    | (у пейдж. частині) | 0x800b76dc | 0x80056874 | 0x80059aa4 | — |

Особливості:

- **RM-159 = RM-320 байт-у-байт** за всіма адресами — та сама база коду N95.
- **N93** має пролог SRAM-рутини `{r1-r6,lr}` (`e92d407e`) замість `{r1-r7,lr}`:
  r7 у цій реалізації не вживається, решта логіки relock збігається.
- **E90** — нестиснутий XIP містить SRAM-рутину й DSP setter (обидва звірено з
  RM-320: setter із маскою `0x1f`), але сама функція-читач множника лежить у
  пейджованій (стиснутій) частині; для E90 читач бере регістр не через цю
  функцію.

## Чого ще бракує для повного профілю

Профіль двигуна має чотири залежні від прошивки поля. Два з них (`iRomSramRoutine`,
`iDspSetter`) підтверджено вище для всіх. Лишаються:

- **`iDvfsBody`** — тіло `dvfs_interface DoControl(1)`, READ-примітив. Це драйвер
  із пейджованого ROFS, а не з резидентного XIP. Для N82/RM-159 (повний CORE
  43 МБ) його можна знайти в образі; для N93/N93i/E90 (лише резидентний XIP) —
  ні, бо ROFS стиснуто. E90 dvfs не має взагалі → `iDvfsBody = 0`.
- **`iPwrDownGlobal`** — глобал даних ядра. Для **E90 знайдено: `0xc8004194`**
  (геттер/сеттер `str/ldr r0,[global,#4]` у power-зоні, `findings.md` §31,
  `e90.md`). RM-320: `0xc80030c8`. Для решти апаратів ще не виводив.

## Стан E90 (апарат для прошивання)

Три з чотирьох полів профілю виведено офлайн: `iRomSramRoutine=0x80056874`,
`iDspSetter=0x80059aa4`, `iPwrDownGlobal=0xc8004194`; `iDvfsBody=0`. Лишився
примітив ЧИТАННЯ для резолвінгу SRAM. Примітив ЗАПИСУ — це RomPatcher+
(`RomPatcherPlus.Driver`), чужий homebrew-драйвер, перезібрати не можна; читати
довільну адресу він не вміє. Бутстрап (рішення користувача): його ж записом
пропатчити користувацьки-доступну функцію ЯДРА E90 як читача (як dvfs DoControl
на RM-320) і прочитати ланцюг `0xc8004194+4 -> obj -> obj+16`. Яку саме функцію —
останнє, що треба з'ясувати; більшість драйверів E90 у стиснутій частині, тож це
крок розвідки на апараті.
