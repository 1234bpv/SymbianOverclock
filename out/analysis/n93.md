- **Prologue vaddr (`iRomSramRoutine`)**: `0x8003e6d0`

> **Note:** In N93, the register save mask in the routine prologue is `{r1-r6, lr}` (`0xe92d407e`), since register `r7` is not used in this implementation (in the RM-320 reference — `{r1-r7, lr}` / `0xe92d40fe`).
